Quality Data Analysis

Statistically validating candidate abrasive backing papers against a production control — using Minitab and a Python cross-check to turn raw tensile and fold test data into a defensible engineering recommendation.

🧪 Project Overview

Abrasive backing paper is the substrate every grit particle gets bonded to — if it tears or folds through during production or use, the whole product fails. When a supplier proposes new candidate papers to qualify against the existing production control, "does it feel about the same" isn't good enough; the decision needs to hold up to quality, R&D, and procurement scrutiny. This project builds that evidence base: a full statistical comparison of one control paper against three trial candidates, across both tensile strength and fold endurance, tested in both the machine direction (MD) and cross direction (CD) of the paper.

Rather than eyeballing four sets of averages, I ran a complete hypothesis-testing workflow in Minitab for each of the four response variables (CD Tensile, MD Tensile, CD Fold, MD Fold): normality testing, equal-variance testing, one-way ANOVA, and Tukey HSD pairwise comparisons — then independently re-ran every test in Python (SciPy/statsmodels) as a cross-check before trusting the conclusions. Along the way, the equal-variance test caught a real violated assumption in the MD Fold data, which changed which test I reported rather than defaulting to the standard ANOVA output.

Why Statistics, Not Just Averages

"With only 9–10 replicates per candidate, a couple of unusual readings can shift a mean enough to look like a real difference when it's just noise — or hide a real difference behind natural variation. ANOVA and Tukey HSD exist to tell those two cases apart, and to say so with a confidence level, not a gut feeling."

✅ Normality Check

Probability Plot — CD Fold by Group

Anderson-Darling normality test, paneled by candidate.

Before trusting an ANOVA, each group's data needs to look reasonably normal. Three of the four candidates passed cleanly; Control came back borderline (AD p = 0.027), traced to two unusually high fold-count readings. Rather than ignore it, I documented the departure and proceeded, since ANOVA is fairly robust to mild non-normality at this sample size.

⚠️ Assumption Check

Test for Equal Variances — MD Fold

Levene's test caught a real assumption violation.

Levene's test came back significant here (p = 0.044) — Control's variance was noticeably larger than the three trial candidates'. That meant defaulting to a standard ANOVA would have been the wrong call; instead I re-ran the one-way ANOVA with the "assume equal variances" option unchecked and reported Welch's test, which is the statistically defensible choice when this assumption fails.

🏅 Statistical Conclusion

Tukey Simultaneous CIs — MD Tensile

Pairwise comparisons pinpointing exactly which candidates differ.

An overall significant ANOVA only says "something differs" — Tukey HSD says what. Any interval that doesn't cross zero marks a statistically significant pairwise difference at the 95% simultaneous confidence level, letting me rank the candidates against Control and against each other in one chart instead of running six separate t-tests.

🔍 Model Diagnostics

Residual Plots — CD Tensile ANOVA

The last check: does the ANOVA model itself hold up?

A significant p-value means little if the underlying model is misspecified. The four-panel residual plot — normal probability, versus fits, histogram, versus order — confirms residuals are reasonably random and normally distributed with no obvious pattern tied to run order, supporting that the ANOVA assumptions held for this response.

From raw replicate data to a defensible recommendation — the four stages every response variable passed through.

Minitab Worksheets Data Cleaning Missing Data Handling

💡 Key Insight: A missing CD Fold reading (noted in the raw comments as "forgot to copy down") could have been zero-filled or silently ignored. Structuring the data as a true blank instead let Minitab correctly report n=9 rather than corrupting the mean — a small decision that mattered for every downstream test.

📐

Assumption Testing

Anderson-Darling Test Levene's Test Probability Plots

💡 Key Insight: Levene's test on MD Fold came back significant (p = 0.044) — Control's variance was meaningfully larger than the trial candidates'. Rather than run the default ANOVA anyway, this flagged that Welch's test was the statistically correct choice for that one response variable, while the standard ANOVA remained valid for the other three.

03
📊

ANOVA & Tukey HSD

One-Way ANOVA Tukey HSD Welch's Test

💡 Key Insight: All four response variables came back significant overall (p ≤ 0.001), but the Tukey groupings told different stories: for CD/MD Fold, Control was the clear outlier and the three trials didn't separate from each other; for CD/MD Tensile, the trials themselves ranked differently from one another — meaning the "best" candidate depends on which property matters most for the end application.

04
🐍

Cross-Validation & Reporting

Python (SciPy/statsmodels) Reproducibility Technical Writing

💡 Key Insight: Re-implementing every test independently in Python wasn't busywork — it's what makes the conclusions trustworthy to someone who wasn't in the room when Minitab produced them. When two independent tools built on different underlying code agree on every p-value and grouping, that's real evidence the result is a property of the data, not an artifact of one piece of software.
